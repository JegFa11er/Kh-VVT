# Дорожная карта (Roadmap) — PF2ERWeb (Foundry-like VTT)

Документ описывает пройденные вехи и детальный план развития виртуального игрового стола (VTT) по правилам Pathfinder 2e Remastered.  
Каждый этап разбит на «Нервы» (UI, сетевые события, стейт-менеджмент) и «Мышцы» (математика правил, канвас PixiJS, физика стен, сохранение на диск).

## Текущий этап: Фаза 4.7 — «Мышцы» холста (PixiJS) и Персистентность

> **Цель этапа:** убрать оранжевые линии-заглушки и превратить клики и удержание мыши в полноценные игровые объекты на карте, а также сохранить мир на диск.

### 4.7.1. Персистентность данных (Сохранение на диск)
- [x] Серверное сохранение `packages/server/data/session.json`.
- [x] Запись/чтение: `directories` (сцены, актёры, папки, предметы, журналы) и `chatLog`.
- [x] Данные не сбрасываются при перезапуске Node.js сервера (`npm run start:server`).

### 4.7.2. Исправление сортировки Компендиума
- [x] Строгий приоритет сортировки в `catalog-service.js`: сначала по `level` (по возрастанию от -1 до 20), затем по `name` (по алфавиту). Записи без уровня идут последними.

### 4.7.3. Измерение расстояний (Линейка PF2e)
- [x] Инструмент `token -> ruler`:
  - Старт от центра выбранной клетки/токена.
  - Путь строится по клеткам алгоритмом Брезенхема.
  - Подсчёт по правилу PF2e (5-10-5 футов по диагонали): первая диагональ 5 футов, вторая 10, третья 5 и т.д.
  - Бейдж с дистанцией в футах над концом пути.
- [x] **Вейпоинты (Foundry-style)**: ПКМ во время удержания ЛКМ ставит промежуточную точку; линейка прокладывает ломаную старт → все вейпоинты → курсор, а 5-10-5 суммируется по каждому отрезку. Промежуточные точки отмечены маркерами.

### 4.7.4. Инструменты рисования (`draw`)
- [x] `rect`: рисование прямоугольника с привязкой углов к узлам сетки.
- [x] `ellipse`: эллипс с привязкой углов/центра к сетке.
- [x] `freehand`: непрерывная линия по координатам мыши без привязки.
- [x] `polygon`: клики добавляют вершины, ПКМ замыкает фигуру (последняя вершина соединяется с первой, тянущаяся линия отбрасывается).
- [x] `text`: клик создает текстовый блок; повторный клик редактирует через `prompt`.
- [x] `select`: выделение рамкой и drag-and-drop рисунков/текста.
- [x] `color`: палитра цвета обводки/заливки.
- [x] `clear`: подтверждение «Удалить все рисунки?» и очистка слоя.

### 4.7.5. Слой Стен и Дверей (`wall`)
- [x] Отрисовка отрезков стен по узлам сетки при ЛКМ + протягивание.
- [x] **Умные стены**:
  - По умолчанию оба конца прилипают к узлам сетки; `Shift` отключает привязку (свободное размещение).
  - Магнитизм узлов: конец новой стены в радиусе 15 px от узла существующей стены слипается с ним (`Shift` отключает).
  - Чейнинг: отпускание ЛКМ с зажатым `Ctrl` сохраняет сегмент и сразу продолжает рисование из его конечной точки; без `Ctrl` непрерывное рисование завершается.
  - Редактирование: у выделенной стены видны маркеры на обоих концах и в центре; перетаскивание концов меняет длину и угол, центральный маркер двигает сегмент.
- [x] Визуальное разделение типов:
  - `normal` (Обычная): сплошная линия (белый/серый).
  - `terrain` (Ландшафтная): зеленая линия (видит через 1 стену, блокирует после 2-й).
  - `invisible` (Невидимая): полупрозрачная синяя (блокирует только движение).
  - `ethereal` (Бесплотная): фиолетовая (блокирует зрение/слух, пропускает движение).
  - `door` (Дверь): иконка двери 🚪 по центру сегмента. ЛКМ — открыть/закрыть (в `token -> select` и `wall -> select`), ПКМ в режиме `wall` — запереть (замок).
  - `secret` (Скрытая дверь): розовая, с собственной иконкой арки (отличается от обычной двери); ЛКМ/ПКМ работают как у двери.
- [x] `clear`: подтверждение «Удалить все стены?» и удаление всех стен.

### 4.7.6. Слой Освещения (`light`)
- [x] `draw`: создание источника света перетягиванием от центра. Длина оттяжки задаёт **тусклый** радиус точно в пикселях (без округления до клеток), **яркий** автоматически равен половине тусклого. Превью показывает оба круга.
- [x] Маркер лампочки в центре источника:
  - Двойной клик открывает диалог ввода радиусов яркого и тусклого света по правилам PF2e (допускаются дробные футы).
- [x] `darkness`: циклическое переключение глобального оверлея затемнения (Светло -> Тускло -> Тьма).
- [x] `gm-vision`: режим зрения мастера (ослабляет затемнение для ведущего).
- [x] `clear`: подтверждение «Удалить весь свет?» и удаление источников.
